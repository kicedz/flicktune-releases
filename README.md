# FlickTune releases

Installers and update files for **FlickTune**, directional sensitivity calibration powered by
[RawAccel](https://github.com/RawAccelOfficial/rawaccel).

Download the latest `FlickTune-Setup-<version>.exe` from [Releases](../../releases/latest).
An installed FlickTune checks this page on startup and offers new versions by itself.

This repository holds release files only; the source code is private.
FlickTune includes the official, unchanged RawAccel runtime (MIT, see the notices installed with the app).
